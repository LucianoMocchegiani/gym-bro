# Reportes

Pantalla Admin: **Reportes** (`/reportes`).

Muestra ingresos y devoluciones por rango de fechas (zona Buenos Aires), más un snapshot de socios y contratos. El default del panel es el mes calendario.

El asistente resume un período (esta semana, mes pasado, etc.). Para comparar dos meses, preguntá los dos: usa dos consultas. **No cobra**.

Hace falta permiso de reportes.
