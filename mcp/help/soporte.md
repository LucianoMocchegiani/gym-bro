# Soporte y contacto

Si alguien **tiene un problema** (no entra, cobro raro, la app falla, un bug, o el chat no alcanza), pasá el contacto de Faciliter. No prometas plazos ni arregles datos por ellos.

**Email:** faciliterapps@gmail.com

Usá este mail para incidentes, dudas de producto que no estén en la guía, o cuando pidan hablar con una persona. También para **cambiar de plan Faciliter o dar de baja el débito del plan** (topic `plan`) y para **coordinar con los técnicos** la instalación de un aparato ZKTeco o un molinete (topic `puerta`). El asistente **no** es mesa de ayuda 24/7.
