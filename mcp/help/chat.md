# Asistente (este chat)

Hay dos usos:

- **Admin:** el botón Asistente (burbuja) abre un drawer. Consulta datos del gym (socios, caja, reportes, packs) con tools. Los chips “ir a…” abren pantallas del panel.
- **Landing pública:** burbuja (misma UI que el Admin). Solo explica el producto (`get_help`). **No** hay un tenant detrás: no hay socios ni caja reales.

En ambos casos: **puede equivocarse.**

En el Admin puede **proponer** crear o editar gastos, afiliados, servicios, packs, clases (puntuales y series semanales), reservas con crédito, lista de espera, staff y roles: muestra una tarjeta y **no se hace nada hasta tocar Confirmar** (vence a los 2 minutos; las acciones peligrosas piden escribir CONFIRMAR). Alta de afiliado o staff sin contraseña → `ChangeMe123!` temporal. **Por seguridad no** cobra, no arma links de pago ni clase suelta, no devuelve plata, no toca débito automático, no abre la puerta, no cambia configuración ni Mercado Pago, no borra ni cancela y no sube archivos: eso se hace en las pantallas del Admin. La landing nunca cambia nada. Para cómo se ve cada pantalla: `get_help` topic `guia`; las fotos están en `/docs`. Para configurar Mercado Pago: topic `mercadopago` (completo). Para carpeta, documentos o rutina como archivo: topic `carpeta`. Si hay un **problema** o piden una persona: `get_help` topic `soporte`.

Cualquier staff puede preguntar cómo usar el sistema; algunas consultas piden permiso extra. En la landing, si quieren contratar: elegir un plan y tocar **Contratar** (alta self-serve con débito de Mercado Pago, `/empezar`) o **agendar una reunión**. Detalle: topic `plan`.
