# Puerta

La **puerta** es el control de ingreso al establecimiento. El afiliado se identifica con la **app** (QR / credencial), no con una captura de pantalla.

El sistema evalúa si puede entrar según pack vigente, deuda, reserva cuando hace falta, y reglas del local. Si se deniega, el motivo tiene que ser legible.

Ejemplo: hay una clase de pilates o funcional; el afiliado entra con la app **para esa clase**. Queda en el historial de ingresos del día.

**Pase manual:** el personal con permiso autoriza a alguien que las reglas automáticas no dejarían pasar.

Pantalla Admin: **Puerta** (`/puerta`). El asistente puede **previsualizar** si alguien entraría hoy, **sin** dejar historial. El ingreso real es en Puerta.

Hace falta permiso de verificación de acceso.
