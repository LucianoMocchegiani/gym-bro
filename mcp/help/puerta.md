# Puerta

Pantalla Admin: **Puerta** (`/puerta`).

El socio muestra la credencial (QR / wallet). El sistema evalúa si puede entrar según pack y reglas del gym. También hay pase manual si tu rol lo permite.

El asistente puede **previsualizar** si alguien entraría hoy, sin dejar historial. El ingreso real es en Puerta.

Hace falta permiso de verificación de acceso.
