# Roles y permisos

Pantalla Admin: **Roles y permisos** (`/roles`). El staff se asigna en **Staff** (`/staff`).

Cada rol tiene códigos (caja, puerta, catálogo, etc.). Los roles de sistema no se borran. Sin el permiso, la pantalla ni la consulta aparecen.

El asistente lista roles y códigos. **No crea ni edita** roles. Cambiá permisos en esa pantalla.

Hace falta permiso de roles.
