# Ideas — capturas pre–definición

Carpeta para **ideas crudas** (charlas ChatGPT, notas con el socio, insights).  
No son fuente de verdad del producto: eso sigue en el C-producto y en [99-backlog-post-mvp.md](../99-backlog-post-mvp.md).

## Cómo usarla

1. Pegás o resumís una charla/idea → un archivo nuevo con el template abajo.
2. Marcás estado: `idea` · `revisada` · `promovida-a-backlog` · `descartada`.
3. Cuando valga la pena construirla, corrés el método de [10-metodo-definicion-producto.md](../10-metodo-definicion-producto.md) y movés lo cerrado al backlog / docs formales.
4. No mezcles ideas con CU/reglas del MVP.

## Convención de nombres

```text
YYYY-MM-DD-slug-corto.md
```

Ejemplos: `2026-07-13-stores-mp-vs-ml.md`, `2026-08-01-waitlist-ux.md`

## Template (copiar al crear un archivo)

```markdown
# {Título corto}

**Fecha:** YYYY-MM-DD  
**Fuente:** ChatGPT / socio / nota propia / link  
**Estado:** idea  
**Tema:** {tienda | pagos | acceso | …}  
**Relacionado:** [99-backlog](../99-backlog-post-mvp.md) — {ítem si aplica}

## Lo bueno (resumen)

- …

## Implicancias para GymBro

- …

## No hacer / evitar

- …

## Siguiente paso sugerido

- [ ] Anotar en backlog
- [ ] Sesión de definición (método producto)
- [ ] Descartar
```
