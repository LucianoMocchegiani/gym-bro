Para mantener las tarjetas de propuestas, habilitar en el perfil `config.chat.confirmUserOnlyTools: true`; el drawer enlaza Confirmar/Cancelar con la aprobación pendiente de `confirm_proposal` y nunca ejecuta argumentos suministrados por el navegador. Confirmar autoriza únicamente los argumentos que Runtime persistió. Cancelar rechaza la aprobación, no ejecuta el MCP de cancelación; GymBro deja vencer la propuesta temporal.
