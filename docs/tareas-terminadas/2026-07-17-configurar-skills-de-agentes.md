# Configurar skills y flujo de trabajo para agentes

**Fecha:** 2026-07-17  
**Roadmap:** Infraestructura de trabajo (fuera de épicas funcionales)

## Resumen

Se incorporaron skills de proyecto para contextualización, ejecución aprobada de tareas, prácticas NestJS/Next.js/Flutter, sincronización documental y registro de cierres.

## Cambios principales

- Skills compartidas en `.cursor/skills/`
- TSDoc obligatorio para contratos TypeScript relevantes
- Dartdoc obligatorio para contratos Flutter relevantes
- Flujo contexto → preguntas → aprobación → implementación
- Registro cronológico en `docs/tareas-terminadas/`
- README e índice de documentación actualizados

## Validación

- Se verificó la presencia de los siete archivos `SKILL.md`.
- Todas las skills incluyen frontmatter y descripción de activación.
